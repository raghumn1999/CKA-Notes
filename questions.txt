Create a network policy to allow egress traffic from the Internal application only to the payroll-service and db-service.

apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: internal-policy
spec:
  podSelector:
    matchLabels:
      name: "internal"
  egress:
   - to:
     - podSelector:
         matchLabels:
           name: "payroll"
     ports:
       - protocol: TCP
         port: 8080
   - to:
     - podSelector:
         matchLabels:
           name: "mysql"
     ports:
       - protocol: TCP
         port: 3306


Ingress condition:
OR condition (multiple items):

from:
- podSelector:
    matchLabels:
      app: frontend
- podSelector:
    matchLabels:
      app: backend
Allow Pods with app=frontend OR Pods with app=backend.

AND condition:
from:
- podSelector:
    matchLabels:
      app: frontend
from:
- podSelector:
    matchLabels:
      app: frontend
      access: "true"
Allow only Pods that have both labels: app=frontend and access=true

Under ingress section,we can add one or more pods without from key, network policy will act as OR condition.
if we add from under ingress section, networkpolicy will act as AND conditon

$ k get networkpolicy --> listing the available network policy
$ k get po --show-labels --> help to fetch labels associated with pods

Complete setup of gateway api on cluster:
1) Install gateway controller: ngixn gateway controller
  $ kubectl kustomize "https://github.com/nginx/nginx-gateway-fabric/config/crd/gateway-api/standard?ref=v1.6.2" | kubectl apply -f -
  $ kubectl kustomize "https://github.com/nginx/nginx-gateway-fabric/config/crd/gateway-api/experimental?ref=v1.6.2" | kubectl apply -f -
  $ helm install ngf oci://ghcr.io/nginx/charts/nginx-gateway-fabric --create-namespace -n nginx-gateway

2) Creation of GatewayClass:
apiVersion: gateway.networking.k8s.io/v1
kind: GatewayClass
metadata:
  name: nginx
spec:
  controllerName: nginx.org/gateway-controller

$ kubectl create -f gatewayclass.yaml
$ kubectl get gatewayclass

3) Configuring HTTP gateway and listener(listener is included in this http gateway):
apiVersion: gateway.networking.k8s.io/v1
kind: Gateway
metadata:
  name: nginx-gateway
  namespace: default
spec:
  gatewayClassName: nginx
  listeners:
  - name: http
    protocol: HTTP
    port: 80
    allowedRoutes:
      namespaces:
        from: All

$ kubectl create -f http-gateway.yaml
$ kubectl get gateway

4) configuring the http route:

apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata:
  name: basic-route
  namespace: default
spec:
  parentRefs:
  - name: nginx-gateway  # name of gateway which is created for this route
  rules:
  - matches:  # matches refer to plural so we can add more path
    - path:
        type: PathPrefix
        value: /wear
    backendRefs:
    - name: wear-service
      port: 8080
    - path:
        type: PathPrefix
        value: /watch
    backendRefs:
    - name: video-service
      port: 8080

$ kubectl create -f http-route.yaml 
$ kubectl get httproute
