Troubleshooting:

Pod is stuck in pending:
 Possible causes:
  Node selector mismatch
  Taints
  No resources
  PVC not bound

  kubectl describe po podname
  kubectl get events
  kubectl get nodes

Pod Crashloopback:
  kubectl logs <pod-name>
  kubectl describe pod <pod-name>
 
  Typical fixes:
   Wrong environment variable
   Wrong ConfigMap
   Wrong Secret
   Application crash

imagePullBackOff:
  kubectl describe pod <pod-name>
  
  Possible reasons:
   wrong image
   Private registry auth issue
   wrong image tag

DNS failure:
  kubectl exec busybox -- nslookup kubernetes.default

look for:
  coreDNS  --> kubectl get pod -n kube-system
  kubelet  --> service kubelet status --> if it is installed on server level
